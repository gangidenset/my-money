はじめに

my-money（以下「本アプリ」）の開発者（以下「開発者」）は、本アプリを使う方（以下「利用者」）の情報を、このプライバシーポリシーに従って取り扱います。

本アプリに入力した家計のデータは、利用者の端末の中だけに保存され、開発者や第三者のサーバーには送信されません。

1. 本アプリが保存する情報

本アプリに入力した次の情報は、利用者の端末のブラウザ内（localStorage）にだけ保存されます。

  • 収入・固定費・予算・貯金額などの家計の設定
  • 支出の記録（日付・カテゴリ・金額・店名・メモ）
  • クレジットカードの請求額・利用額、目的別の貯金、ボーナスの記録
  • 表示モードやバックアップ日時などのアプリの設定

開発者はこれらの情報を見ることも、集めることもできません。

2. 開発者が集める情報

開発者は、本アプリを通じて利用者の個人情報を集めていません。

  • アカウント登録はなく、氏名・メールアドレス・電話番号などは求めません
  • 銀行口座やクレジットカード会社との連携はしません
  • 広告は表示せず、広告用の識別子も使いません
  • アクセス解析ツールや Cookie による追跡は使っていません

3. 配信サーバーの記録

本アプリのファイルは GitHub Pages（GitHub, Inc. の提供するサービス）から配信しています。アプリのファイルを読み込むとき、GitHub がセキュリティなどの目的で、IP アドレスなどのアクセスの記録を残すことがあります。この記録は GitHub のプライバシーに関する方針に従って取り扱われ、開発者は受け取っていません。家計のデータが送られることはありません。

4. 利用者が自分で書き出す情報

次の機能を使うと、利用者の操作でファイルが作られます。ファイルの保存先や共有先は利用者が選び、開発者には送られません。

  • バックアップを保存：家計のデータをまとめたファイル（JSON 形式）。共有メニューで選んだアプリ（ファイル・LINE など）に渡すと、そのサービスの方針に従って取り扱われます。家計の情報が含まれるので、保存先に注意してください
  • カレンダーに登録：給料日・ボーナス月の予定（.ics 形式）。金額などの家計のデータは含みません

5. データの削除

本アプリの「設定」→「すべてのデータを削除」で、端末に保存されたデータをすべて削除できます。アプリをアンインストールしたり、ブラウザのサイトデータを消したりした場合も削除されます。削除したデータは開発者にも復元できないため、必要に応じてバックアップを保存してください。

6. 子どもの利用

本アプリは個人情報を集めないため、年齢にかかわらず同じように利用できます。

7. このポリシーの変更

機能の追加などにより、このポリシーを変更することがあります。情報の取り扱いを大きく変えるとき（クラウドへの保存や有料プランの追加など）は、変更前にこのページとアプリ内でお知らせします。
